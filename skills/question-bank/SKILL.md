# Question Bank

## Discuss the answer

Use relevant private `profile.json` facts, linked project evidence and matching `questions.json` ideas from the [workspace map](../../docs/data.md#workspace-map). Explain what the question tests when useful, select documented examples and ask only for missing facts or personal choices. Summarize the proposed answer direction; draft final wording when requested.

## Save approved ideas

After the user approves the idea, use [save-idea](../../docs/commands.md#maintenance). Save the supplied question, a broad category and a concise answer direction. Reuse a matching entry; employer-name, length or wording changes alone create no new idea. Read back the saved row. Synchronize the same idea to a configured [external question bank](../../docs/integrations.md#notion), reporting pending writes accurately.
